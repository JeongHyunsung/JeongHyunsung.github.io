Relay privacy policy

Effective 1 November 2026 · Applies to Relay 1.x for Windows

Relay keeps short notes about the work you have in progress on your PC. It has no account, no server and no analytics. Nothing you put into Relay leaves your computer.

What Relay stores

  • The contexts you create: a one-line memo, an optional note and link, the kind of work and tool you picked, and timestamps.
  • Where each context came from: the program name, its window title, a window handle and, for coding agents, the working folder.
  • Your settings, and a random access token for the local agent connection described below.

This is saved as JSON files in Relay's own app-data folder on your PC. You can open that folder or export everything from Settings › Your data. Uninstalling the Microsoft Store version removes it.

What Relay reads, and when

  • When you capture a context (shortcut or the + button), Relay reads the title and program name of the window in front. If that window is a web browser, it also reads the address bar so it can reopen the same page later.
  • When you click a context, Relay looks up that window again to bring it to the front.

Relay never records your screen, keystrokes, clipboard, files or the contents of your conversations with AI tools.

Connecting coding agents

If you choose Connect for Claude Code or Codex in Settings, Relay adds one entry to that tool's configuration file on your PC (.claude\settings.json or .codex\config.toml) and saves a backup copy first. The entry makes the agent tell Relay when it starts or finishes a turn. Disconnect removes only Relay's entry.

Those notifications go to a port that only programs on your own PC can reach (127.0.0.1) and must carry Relay's access token. Relay ignores requests from web pages. The agent sends its session id, working folder and, when a prompt is submitted, the first line of that prompt, which Relay uses as the memo.

Sharing

Relay does not send data to the developer or to anyone else. It contains no advertising, tracking or third-party analytics. If you use Microsoft Store, Microsoft may collect installation and crash data under its own privacy statement.

Children

Relay is a productivity tool and is not directed at children.
